# TechPortfolio

Portafolio de soluciones TI con cinco vistas, un catálogo interactivo y un formulario de contacto con integración opcional de EmailJS.

El código de la aplicación está en `TechPortfolio-CodeSandbox`. Consulta el [README técnico](./TechPortfolio-CodeSandbox/README.md) para instalarla, configurarla y ejecutar las pruebas.
